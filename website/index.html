Write

Keep as many notes as you like.

Type / for headings, checklists and code, and ⌘ P to find any note. Each one is a plain Markdown file you can sync with Dropbox, iCloud Drive or git.

Snippets

Type !sig, get the whole signature.

Give text you type often a keyword. Type it in any app, in an email, a chat or a form, and Waypoint swaps it for the snippet, with {date} and {clipboard} filled in. Your clipboard is put back after.

  commands: {
    'team-links': {
      view() {
        return {
          type: 'list',
          items: links.map((link) => ({
            id: link.url,
            title: link.title,
            icon: { builtin: 'link' },
            actions: [{ type: 'open-url', url: link.url }],
          })),
        };
      },
    },
  },
